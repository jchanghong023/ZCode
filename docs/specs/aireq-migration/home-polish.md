# 主页面阅读密度打磨

2026-11-17 用户要求 Impeccable polish：以外观页的正文比例与留白为基准，主页面降低文字负担；右侧面板展开后正文按剩余空间收窄、居中，并统一所有页面标题。整体正文容器由 shell/pageLayout 统一持有，本节只规定项目总览、当前项目、想法池、我的待办的局部信息密度。

## 范围与规则

- 保留既有视觉体系、所有业务数据与入口、唯一导航和业务 owner；只调整呈现层级，不新增服务、状态缓存或写入路径。
- 项目总览的页面说明移入既有具名帮助入口，首屏优先呈现标题、添加项目及项目／版本比较。默认每个项目只显示创建时间最近的两个版本，其余使用既有展开／收起入口；本条覆盖旧默认四项的局部展示规则。只读卡片、排序、数据及整体正文列内的左对齐不变。
- 当前项目的进度计算规则与确认分类重叠说明移入既有帮助入口，不常驻大段解释。未分析 SR 数仍直接显示，统计及近期动态完整保留。长职责说明允许在固定阅读宽度内自然换行，不通过裁切隐藏必要动作。
- 我的待办保留我的／待认领／全部三个独立筛选和对应数量，改为紧凑的带数字筛选行，去掉三张大统计卡及紧随其后的重复标题。当前筛选用 aria-pressed、选中底色及键盘焦点表达。范围仍严格匹配当前项目与 Release，默认当前工号，分配／认领操作不变。
- 想法池移除重复全局范围说明；侧栏已明确全部项目，页面保留标题、导入导出、新增与搜索。结果、错误、确认及恢复操作保留。
- 各页内容间距使用同一系统节奏，区块间留白大于区块内部；在父容器缩窄时按钮组换行，表格只在自身区域横向滚动，不撑开正文。

## 验收

在当前深浅主题、宽／窄电脑浏览器、右侧面板关闭／展开状态检查标题、正文居中、留白及无页面水平溢出。确认总览帮助入口可用、进度／未分析数量不丢失、待办三筛选数量与行数不变、想法池导入导出与转入操作仍可到达。共享类型、Lint（含 Hooks）及架构检查由主集成收口；局部修改先做格式与源码检查。

## 正文配色与外观页统一（2026-11-17）

- 用户要求想法池、当前项目、需求共创同时统一文字与内容背景。页面底色仍为 `bg-background`，表格及项目数据区使用外观设置行的 `bg-card` / `border-card-border`，不以页面底色或 `bg-surface` 代替内容卡片。
- 标题、字段标签、提交人和主要数值使用 `text-foreground`；原始需求长正文、编号、日期、补充说明与空态使用外观说明文字的 `text-foreground-subtle`。当前项目正文不再混用侧栏专用的 `text-remote-foreground-muted`。状态徽标及主操作保持原有语义色。
- Zai Dark 的共用次级文字在卡片上的原对比度约 4.44:1，微调既有 token 的透明度，使外观页和业务正文一起达到至少 4.5:1；不增加页面专属灰色。
- 仅调整呈现，不改变项目／Release 选择、筛选、排序、确认门禁、数据 owner 或写入路径。表格粘性表头使用同一不透明卡片底色，滚动时不透出正文。
- 验收：深浅主题分别比较外观设置卡片、三页表格／数据区的计算背景色和主／次文字色；检查 1440px 与 1100px 电脑窗口、表格滚动、搜索空态、想法编辑及提案讨论入口，确认没有页面横向溢出。

## 其余主页配色收口（2026-11-17）

- 项目总览的 Release 阅读区与无项目空态使用同一 `bg-card`、`border-card-border`；项目名称、版本标题及百分比保留主文字色，版本数量、统计说明与无数据提示使用 `text-foreground-subtle`，不再借用侧栏灰色。
- 我的待办表格使用卡片底色，表头为主文字色；筛选计数仅选中时提升为主色，其他计数为次级色，悬停／键盘聚焦提升对比度。表格行的悬停及行内焦点同步提升辅助文字，业务状态色不变。
- 保留全部项目／Release、展开收起、过滤与待办分工行为；不改事实、排序或服务调用。深浅主题与 1440px／1100px 电脑窗口核对配色、空态、版本展开及待办三筛选。
- 用户进一步指出总览正文过窄：“添加项目”移到页面标题和帮助旁，标题操作不再分占正文两端。项目分组铺满统一正文列，版本区在足够宽的所属面板中使用两列等宽网格，较窄时单列；无版本项目也不收窄。删除按可见版本数量和固定卡宽计算外层宽度的规则；本条覆盖历史“完整列收边／卡片不拉伸”限制。默认两个最近版本与展开全部不变，按钮仍经原导航门禁进入添加项目。
