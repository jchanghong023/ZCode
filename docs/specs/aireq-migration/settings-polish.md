# 设置正文比例与说明减负（2026-11-17）

用户授权使用 Impeccable polish，并明确以外观页及 ZCode 上游原生设置比例统一主页／设置页：正文在当前可用容器内居中、保留留白、侧栏变化时随容器收窄，标题位置和字号一致。本文件记录设置部分；不修改业务协议、保存/取消/离开门禁、搜索定位、模型与指令草稿所有者。

## 依据与范围

- 当前共享 `SETTINGS_FRAME_CONTENT_CLASSNAME` 与上游 `fec97590` 同为 `mx-auto w-full max-w-4xl px-4 pb-8 pt-0 lg:px-8 lg:pb-10`。AIReq 设置页自行使用的 `max-w-5xl` 偏离该比例；改为直接复用共享常量。
- 设置正文滚动面与主页统一 `scrollbar-gutter: stable both-edges`，内容相对可用面板几何居中，不因单边预留滚动槽偏移；横向滚动由局部表格承担。
- 标题使用与主页统一的外观角色 `text-ui-settings-title font-semibold tracking-tight text-foreground lg:text-ui-settings-title-lg`，保留 h1 页面语义。
- 外观控件及主题预览行为不改。设置页正文保持较大的组间间距，以标签和实际控件为主；重复解释归入原生可展开说明，业务边界不删除、不改成虚假能力。
- 模型页将团队共享／新会话生效范围合并为精简提示，完整说明可展开；Agent 职责与思考强度解释合并到“配置说明”，默认只展示具名 Agent、模型及思考强度控件。原有草稿汇总、保存／取消及错误反馈保留。
- Agent 指令页保留 Agent 选择、当前职责、字节限制与保存行为，合并重复的团队共享／生效范围文字。
- 项目配置保留项目／Release 数量、仓库、分支、编辑与添加 Release；Release 明细改为默认折叠的原生 disclosure，计数及添加操作始终可见。团队共享及 Release 业务含义改为可展开说明，不在卡片上方重复铺陈。
- 分析设置精简常驻过程解释，保留开关／间隔／范围／保存状态及实际影响说明，详细规则可展开。

## 验收
