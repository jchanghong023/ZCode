# 分区导航

需求共创按项目和 Release 列出需求，每行展示最新文档版本及确认状态，详见[需求共创](proposals.md)。

## 导航与范围

工作台面向电脑浏览器。全宽顶栏左侧为品牌、「项目总览」与「需求共创」，右侧依次为角色管理、在线人数、帮助、当前工号与设置。点击顶栏的工号打开菜单，首项为「切换工号」，下方依次为「界面主题」和「界面缩放」。角色管理在页内选择项目，设置覆盖层有独立分区目录。

总览标题行切换项目，近期版本列表用于原位选择 Release。概览按钮与顶栏「需求共创」都打开当前预览版本，无近期版本时可进入项目全部需求。「项目全部需求」始终打开所有年代和未分配的 IR。共创标题行含项目、版本范围选择器以及筛选前的 IR 总数，切换同项目版本保留查询。进入会话后在顶栏标记需求共创，返回原范围。顶栏与页面入口统一走现有导航门禁。

当前页面使用选中底色、较强字重及 `aria-current="page"`，键盘焦点独立可见。两个 Agent 会话均归属需求共创，返回列表时保留原范围。

钴蓝日间的顶栏与设置目录使用同一浅蓝底色。当前项使用淡蓝填充和整圈边线，鼠标悬停提示独立于当前位置。键盘焦点在当前项和普通项上都可辨认。

进入需求共创或 Agent 时，焦点落到当前页面标题。从总览停留项的详情进入讨论时保留所选版本，返回项目总览后聚焦原停留项并恢复其展开范围。从需求共创进入讨论再返回时优先聚焦原需求入口，条目已离开当前筛选范围时聚焦列表标题。

工作台顶部提供“跳到主内容”跳过链接：默认 sr-only，键盘聚焦时可见，激活后聚焦并滚动主内容区；不新增导航 owner，不改变鼠标布局。

`AIReqContext` 唯一持有项目、Release、对象、主页面、浏览器历史及未保存门禁。首页「项目全部需求」打开项目级需求共创，「查看本版本的 N 条 IR」通过 `openProject(projectId, releaseId)` 选择项目和指定 Release，直接打开版本级需求共创。切项目保留页面类别，详情回对应列表；进入项目时默认查看全部需求，点击首页版本先原位查看概览，从版本概览进入需求共创时筛选到该 Release。无显式对象链接时，登录和重新加载网页进入「项目总览」。显式对象链接同步对象所属项目及 Release。需求链接包含项目、IR、可选 Release、SR 和 Agent；SR 仅在浏览器定位文档，会话仍按项目、IR 和 Agent 读取。缺项、归属错误或对象不存在时仍按既有规则明确报错，不使用普通导航的范围回退掩盖错误。

`navigationState.ts` 校验浏览器历史中的页面和覆盖层。关键字与列筛选作为当前登录页面内的界面状态，由 `AIReqContext` 按自己的浏览器历史槽保存。后退／前进从原槽恢复关键字和列筛选，分页从第一页开始，不恢复旧页码。切换项目清空筛选并回到第一页；同一项目内切换 Release 保留筛选，也回到第一页。打开设置或需求会话再返回时保留当前筛选。从首页重新进入项目全部需求或指定版本时清空旧列表筛选；「未分配版本」入口设置对应筛选。筛选值不进入 URL 或服务端。主区进入 Agent 使用当前需求和明确的 Agent 选择，表格查看文档只影响侧栏。

```mermaid
flowchart LR
  A[项目总览：选择 Release] --> B[AIReqContext 记录页面、项目与 Release]
  B --> C[需求共创]
  C --> D[需求或方案 Agent]
  D -->|经离开门禁返回同一 Release| C
```

导航、切范围、设置往返及历史切换沿用既有未保存门禁；取消或保存失败不改变已接纳选择和历史。目标投影未就绪显示读取中，失败显示错误与重试，不用前一目标快照推断空版本、零统计或缺材料。同目标后台重读保留已读内容、滚动和未处理的提交错误，迟到结果不得覆盖新目标。丢弃未保存修改后只继续一次原导航，在途保存期间不重复提交或丢弃。

普通导航的当前范围在有效云龙快照中消失时，若项目仍在而所选 Release 不在，明确切到该项目的「全部需求」，同步更新当前范围、页头选择与列表，不以失效的 Release 选择展示全部数据。若项目已不在目录，返回「项目总览」。读取失败不视为范围消失。

## 页面与正文

宽桌面主区两侧各留 24px，1100px 桌面各留 16px。页面名和范围选择器在共同基线上。总览左列约占三格，右侧版本概览九格；有文档更新时宽桌面以约二比一展示停留列表和动态，窄桌面上下排列并各显示前三条。无更新时动态缩成一行。需求列表占完整主区，开启文档后使用七比五的分栏；讨论会话与文档使用等宽起点，可拖动调整或展开完整视图。

项目已加载且没有 Release 时，可以进入「全部需求」。云龙读取失败时显示错误并提供重试。

Agent 工具栏提供「返回需求共创」，经离开门禁回到同一项目和 Release。验收覆盖 1100×700 的文档阅读、没有 Release 时仍可打开项目需求列表，以及 1440×900 完整布局。

设置与阅读页在实际剩余面板内居中。项目总览与需求共创共用主区左右边距、标题左边线与顶部基线。需求共创在主区铺开，表格仅局部横滚。两页复用 `shell/pageLayout.ts` 的标题角色。

项目总览和需求共创保持共同标题基线。需求共创页头通过选择器显示项目名与版本范围，并显示该范围内筛选前的 IR 总数。两个 Agent 会话以 IR 名称为主标题，省略和版本完全匹配的标题前缀，次行显示项目与版本，提供返回和查看文档，输入框提供按需评审。会话链接包含项目、Release、需求和 Agent。

卡片与数据表使用 `bg-card`／`border-card-border`；标题、主要数值使用主文字，需求原文摘要、版本确认信息和说明使用次级文字。需求表的粘性表头与固定列使用一致的不透明表头底色。重复范围和过程解释进入已有帮助或 disclosure，错误、过期和操作门禁仍直接可见。

输入占位符（含 Select 未选值与聊天输入器占位）使用次级文字 `foreground-subtle`，在所属输入表面保持 ≥4.5:1 对比；`foreground-subtlest` 只用于徽标、刻度等弱元信息，不承载字段说明。

顶栏的「帮助」可直接打开业务流程帮助。关闭弹窗后焦点回到本次打开帮助的按钮。业务流程帮助按黄区澄清、单向交接、红区做方案和各区定版组织，区分全项目交接和发送单条 IR 的云龙评论。

## 项目总览

- 首页默认查看第一个可见项目。项目切换后，左侧只列最近 12 个月的 Release，以该版本全部 IR 中最新的有效创建时间为更新时间，按时间倒序。按北京时间日历计算范围，版本内的旧 IR 也计入统计。右侧默认选中最近版本，点击其他版本原位切换。项目读取失败显示重试入口；近期版本列表下方同一行提供「项目全部需求」和带数量的「未分配版本」；未分配数为零时只显示全部需求。没有近期版本也可使用这些入口。
- 当前项目名是首页主标题和项目切换入口，与需求共创的标题左对齐。项目配置由设置进入。版本标题使用卡片底色和细分隔线，钴蓝日间以蓝色主按钮进入本版本的 IR。项目与版本选择器保留可见键盘焦点。
- 近期版本在同一列表内导航，时间范围和排序说明紧邻列表。当前版本通过整圈边框和浅底标明；允许动效时切换底色与边框用 140ms 过渡，数字同时更新，减少动态效果或性能模式下直接呈现。版本行显示完成数和总数。所有 IR 均已完成且总数大于零时，使用绿色进度条和勾选图标。右侧四项指标按整个版本计算：IR 总数、云龙已完成数及完成百分比、已有正式定版文档的 IR 数、当前阶段「停留 ≥30 天」的未完成 IR 数。正式定版包含当前或历史确认过的正式需求文档，同一 IR 只计一次。
- 未完成 IR 按当前阶段停留时间降序排列，复用需求共创的阶段起点、标签及当前责任人字段。同一行显示标题、阶段、责任人和时长。责任人显示来源姓名或工号，缺失显示「—」。停留按完整天数分档：30 至 90 天为橙色，超过 90 天为红色。起点缺失显示「—」，排在末尾并排除在停留指标之外。
- 停留列表和最近文档更新仅省略标题开头与当前版本名完全匹配的「版本名 ·」前缀。点击停留项读取完整原题。详情标题区按该 IR 可访问的会话提供「讨论此需求」或「讨论此方案」。点击文档更新进入该版本并打开对应 IR 文档。更新按正式 IR 正文实际提交时间倒序。每组默认最多五条，窄桌面默认三条，可展开全部。无更新时只显示单行提示，停留列表使用整栏。
- 「查看本版本的 N 条 IR」进入所选 Release，「项目全部需求」进入当前项目所有年代、所有版本及未分配 IR。未分配数量按整个项目计算。验收覆盖历史版本、项目无近期版本、缺失日期，以及 1440×900、1100×700 下两页标题对齐。

需求共创默认使用「精简」列配置，依次展示标题、需求编号、当前责任人、文档版本和操作。表格有剩余宽度时，按进展、停留时间、预估与卷积工作量、开发责任人、测试责任人的顺序显示能放下的列。PI 可通过列配置开启，项目和 PI 范围仍可通过导航及筛选选择。「当前责任人」取云龙 IR 的 `delivererOwner`，为空时显示「—」。需求共创缩小左右留白，在 1100×700 窗口检查默认列完整可见。精简布局放不下独立停留列时在进展下显示时长；主区进一步变窄时将进展与时长一起放到标题下。固定操作列挤占版本链接时，精简布局依次将编号、当前责任人并入标题。自定义列沿用显式选择。最长标记比较当前筛选结果中全部未完成且阶段时间有效的 IR，并列同样强调。标题列以 176px 为起点，其他可见列和操作列排下后优先使用剩余宽度，最多 320px，标题默认最多显示两行；在指定版本内可省略与页头完全相同的「版本名 ·」前缀，全部需求、搜索命中、可访问名称和详情保留完整原题或原题命中片段。点击可打开 [IR 详情](proposals.md#ir-详情阅读)，查看完整描述、评论、业务字段及可展开的原始字段。搜索命中原文时，在标题下显示匹配片段。PI 显示 Release 名称，未分配时显示「未分配」。「文档版本」显示「Vn · 已定版」「Vn · 草稿」或「暂无文档」。点击版本可直接阅读文档及其确认人和确认时间。草稿下方的「上次定版 Vn」直接打开对应历史快照。创建和确认时间使用北京时间，完整历史定版记录可从文档区查阅。

筛选工具栏沿用卡片底色，表头以不透明浅层底色与数据行区分。长列表只在表格内纵向滚动，列名固定在表格视区顶部。在页头、筛选栏或列表末尾继续滚动时，页头、筛选栏与列名保持可见；打开文档分栏后同样适用。鼠标经过行或键盘聚焦行内控件时，整行与固定列使用一致底色，已打开的文档行保留选中态；讨论入口常驻可见。

每个 IR 按服务端返回的可访问会话提供入口。有需求会话时主操作为「讨论需求」；只有方案会话时主操作为「讨论方案」；没有可访问会话时仍可「查看文档」。同时有两个会话时，「更多操作」优先提供「讨论方案」；紧凑布局将两个讨论入口相邻排列。返回列表时优先聚焦原行中该会话的入口。各入口的可访问名称包含对应需求。命令预览与复制规则见[在开发仓库中查看最新文档](proposals.md#在开发仓库中查看最新文档)。主区较窄或开启更多列时，表格在自身容器内横向滚动，表头、列顺序与排序入口保持可用。滚动内容经过固定列时显示边界，键盘定位时为两侧固定列预留空间。打开右侧文档时留在列表并聚焦所选文档标签；列表高亮当前需求，将该行保持在表格视区，收起后回到打开文档的入口。

只有服务端允许向红区交接时才显示全量同步入口。黄区页头提供「刷新项目」，全量同步归入「项目交接」菜单，数据规则见[黄区到红区的全量同步](proposals.md#黄区到红区的全量同步)。刷新保留仍有效的 Release、筛选和列配置。同步状态和错误属于当前页面，切换项目或 Release 时保留。菜单项显示「同步全部项目到红区」并说明同步内容和自动同步频率，在途禁止重复触发。菜单收起后仍显示交接回执或错误。

页头、筛选栏和表格外边线对齐。工具栏将已选字段、关键词和输入框放在同一行，空间不足时换行。点击输入框可选择常用字段或搜索筛选字段。新字段以待选条件显示在输入框前，勾选后点击「确定」应用。「清空」只清除本次勾选，关闭面板丢弃未确认的修改。关键词输入时实时搜索，按 Enter 或离开输入框后显示为可移除条件。横向滚动表格时从对应表头筛选。PI、人员、文档版本、进展、标签及其他分类字段用漏斗打开选项面板，支持按关键词搜索、逐项勾选及全选当前搜索结果。标签数组按单个标签匹配，缺值可按「未设置」查找。同列选项满足任意一项即可，跨列筛选需同时满足。无勾选时该列不限制结果。每个条件可通过右侧关闭按钮单独移除，也可一次清除表格筛选和关键词。项目和 PI 的单选范围继续由页头控制，清除表格筛选时保留页头范围。列筛选选项来自项目快照，修改筛选回到第一页。切换项目清空筛选，同一项目内切换 PI 保留列筛选。

工具栏的「列配置」可应用「精简」「责任分工」或「全部字段」预设，按名称搜索字段，并按基础信息、用户字段、日期字段、数字字段、选项字段和文本字段浏览，单独显示或隐藏数据列，并在「已选字段」区拖动调整列顺序，也可用上移、下移按钮操作。全部字段预设包含 AIReq 列和有明确来源的云龙 IR 列。云龙字段名沿用门户，创建时间取 `createDate`，预估和卷积工作量在同一列显示。IR 长描述、评论和附件元数据在详情读取。云龙快照缺少的字段显示「—」。人员列按各自的云龙字段显示，空值不从其他人员字段补齐。操作列固定在表格右侧，横向滚动时始终可达。主区较窄时，行操作集中到菜单。宽度允许且标题或编号在首列时固定该首列。隐藏标题后可从操作列查看 IR 详情。编号、日期、工作量及其他可排序列的表头可按键盘或鼠标排序，重复激活反转方向，空值排在最后。排序在分页前作用于筛选结果，切换排序回到第一页，默认按创建时间降序。列配置和排序按连接工号保存在服务端，同一工号跨项目、浏览器及服务重启后复用。自定义配置按选定的列和顺序显示。旧精简配置沿用新版精简布局，保留原排序。旧配置按 PI 排序时继续显示 PI。首次没有服务端记录时，从当前浏览器迁移已有配置。保存失败时保留本次编辑并提示重试。「恢复默认」恢复精简列和默认排序。表格底部显示当前 PI 范围内的匹配数与总数，多页时标明本页条目范围，翻页保留键盘焦点。无匹配结果时，提示及清除筛选入口保持在主区可见范围内。

搜索命中需求标题或原文时，在对应位置显示包含第一处完整命中的片段，保留前后文并标出省略。搜索片段可超过两行，确保完整显示命中。需求编号匹配时保留原行的显示规则。通过键盘激活标题打开详情，按 Esc 逐层关闭全屏阅读和详情，最终回到该标题。搜索词和筛选由现有表格持有，原文查看只影响当前行的阅读状态。验收在 1100×700 搜索位于长原文后部的词句，核对结果行可见命中、键盘展开完整原文，以及关闭后的焦点。

精简表格在窄分栏放不下基础列时，保留标题、文档版本和操作，将需求编号与完整责任人工号放在标题下；手动列配置继续按既定顺序局部横滚。列表页头的范围选择器与操作位于两栏上方，随页面宽度换行；可容纳文档图标与更多菜单时，保留逐行查看文档的入口。右侧文档区无当前文档时提供「讨论需求」入口。展开右栏导致表格重新换行时，正在查看文档的需求行仍保持在表格视区。

验收覆盖登录落在「项目总览」、总览可在标题行切项目、键盘或鼠标从版本详情一步进入需求共创且范围一致、从项目页面打开「角色管理」后可在角色页内选择项目。浏览器前进／后退恢复页面、项目及 Release。未分配 Release 的需求可在「全部需求」中查阅。深浅主题及宽窄电脑窗口检查标题对齐、焦点和页面宽度。

前端验收：

- 在同一项目的两个历史槽分别设置关键字和列筛选并翻到第二页，后退／前进时核对恢复目标槽的查询，但从第一页显示；切项目清筛选并回到第一页，切同一项目的 Release 保留筛选并回到第一页。
- 刷新时交错发送业务通知和旧快照响应，核对最后的标题、范围选择器、列表和统计仍使用成功刷新的云龙快照，本地业务更新不丢失。
- 刷新后若当前 Release 不再存在，确认标题、范围选择器与列表同时切为该项目的「全部需求」；若当前项目不再存在，确认回到「项目总览」。缺项、归属错误或目标不存在的对象分享链接仍显示既有错误。
- 从一个 Release 发起红区同步，在请求未完成时切换项目及 Release，核对按钮仍指示同步中且不能重复提交；让请求失败后再次切换范围，核对同一错误仍可见。

## 全系统在线人员

顶栏右侧、当前工号菜单前提供“在线人数”入口，不受项目或 Release 选择影响。入口复用 ghost 按钮与顶栏图标／文字基线，以辅助文字显示标签、主文字右对齐显示“N 人”；32px 行高，悬停、弹窗打开及键盘焦点均有清晰反馈，不添加装饰状态点或循环动画。读取中显示“在线人数…”，失败显示“在线状态暂不可用”，两者均不显示人数。点击打开复用现有 Dialog 的居中弹窗，宽 640px、最大高度 70vh，仅显示“工号／访问 IP”两列；固定不透明表头，名单内部滚动，IPv6 完整换行。无搜索、分页、头像、逐行在线标记或其他操作；关闭按钮、Esc 和遮罩关闭后回焦入口。人数按工号去重，包含自己；行按工号与 IP 去重并稳定排序，同一工号的多个 IP 分行显示。工号非可信认证，不将人数称为已认证用户。

连接事实由服务端 AIReqPresence owner 持有，仅接纳校验成功并已打开的 WebSocket；注册／注销幂等，同 IP 多连接按引用计数，最后一条连接关闭才删除该行。只读快照 readPresence 与 presence 事件复用现有 AIReq Channel RPC，携带进程内递增 revision，事件不触发业务工作流重读。客户端先订阅再读，忽略迟到旧版本，每 15 秒补读以恢复暂时读取失败；不得自动重放写命令。断线由既有 main 连接 owner 管理；读取失败显示“在线状态暂不可用”，不将旧数值当实时结果。进程重启清空连接表，当前单进程部署不宣称跨实例汇总。

IP 取宿主 requestIP，缺失显示“未知”；默认忽略转发头。ZCODE_TRUSTED_PROXY_IPS 以逗号配置精确可信代理 IP，仅当直连来源在该列表时，从右向左剥离可信 X-Forwarded-For 地址，取首个不可信来源；非法链退回直连地址。连接保活使用 WebSocket ping/pong，60 秒空闲超时清理失联连接，不依赖用户操作，不保存访问历史。

```text
WebSocket open／close → 服务端 presence owner → 去重快照 revision → presence 事件
客户端订阅 → readPresence → 版本核对 → 人数入口与弹窗只读投影
```

验收覆盖两个工号实时互见、同工号多标签与多 IP 去重、关闭／切工号移除、伪造转发头不生效、可信代理链、迟到快照、真实长名单滚动不跳位置、IPv6、浅深主题、键盘焦点与弹窗关闭。在线数据只来自连接，不生成演示名单。

## 主页面对象标识展示

项目总览和需求共创默认只展示可读业务内容，不在名称列或摘要中渲染内部对象 ID，也不将其称为业务编号。名称不足时不以内部 ID 兜底；保留需求名称、状态、人员工号和时间。

表头与搜索提示使用原始需求或名称；现有内部 ID 精确检索能力保留用于已有定位流程，不另造展示编号。操作按钮的无障碍名称使用对象名称与动作。对象 ID 仍用于内部关联、导航和详情追溯；不改服务契约、数据身份或状态所有者。

验收：逐页检查默认列表与 Release 卡片无内部 ID；通过 SR 链接仍能定位对应文档；筛选、展开和详情操作指向原对象；浅深主题均保持可读。
