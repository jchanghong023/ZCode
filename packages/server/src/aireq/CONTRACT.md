# AIReq 模拟服务端契约

## 业务事实与原生运行时

工作流是需求、项目角色、当前材料、已确认快照和文档评审记录的唯一写入方。每条需求属于一个项目与 Release，创建时同时绑定独立的需求和方案会话。所有有效工号可以读取文档和进入需求会话。项目的开发或测试可进入方案会话、读取方案评审及确认版本。管理员沿用全项目角色。角色校验适用于业务命令、原生会话读取与再次执行、目录和附件访问。项目地址与默认分支保留作正式后端的只读代码入口。

纯对话无文件变化时保留原版本。新建短需求时没有文档版本，首次写入文件生成 V1。未确认的同版可反复修改。`validateDocumentVersion` 只读检查完整性及格式并返回 `snapshot`。确认先核对提交的快照仍匹配未定版的版本及全部文件，再按当前规则复核，成功则固定文件、SR、确认人工号和时间。文件漂移、版本变更或已定版时 RPC 拒绝；快照匹配但复核未通过时结果含失败的 `receipt` 与同级 `documentValidation`，报告问题路径和原因。版本号在确认时保持不变，确认后的首次文件变化把固定快照移入历史并开启下一版。删除文件保留版本计数，已有确认记录的需求受历史留存规则保护。

项目保存校验代码源配置并准备本地共享文档目录。工作流在提交材料变更前发布该 IR 的完整最新版，确认快照独立保留。详见[项目工作目录](../../../../docs/specs/aireq/contract-design.md#项目工作目录)。

原生会话、附件、队列、订阅及水位归 `MockRuntime/MockZCodeAgentService`。工作流提交业务事实后发出更新通知。已接纳输入保留原工号、连接 ID 和正文，执行按会话绑定的模型、指令及实际输入路由，提交材料前重验操作权限。两个 Agent 写入各自的材料，继续在同一会话讨论。模型配置和追加指令共享四个角色。模拟后端只处理内存材料，原生会话回复与评审记录只描述实际处理结果。

## 按需评审

`reviewDocuments` 在工作流接纳时记录最新文件快照、版本、请求工号、时间及独立评审角色配置。固定提示词经原生队列在发起评审的会话中调度，只读子代理把报告返回相同会话，同时结算工作流评审记录。停止或失败可重新发起评审；评审不会写文件、确认版本或阻塞确认。当前文件清单变化使对应旧快照的报告标为旧内容，即使版本号相同。

模拟运行时使用原生工具和子代理行显示内存检查结果。评审快照和模型绑定在接纳时捕获，排队时不会被后续聊天、修改或配置变化覆盖。其他输入保留其投递身份，评审运行期间的聊天随后处理。模拟服务不访问真实模型、仓库、数据库或业务文件。正式运行时需由真实子代理执行相同的只读任务。

## 调用与回执

公开 `MockAIReqService` 由 `@zcode/services/aireq` 的接口与 descriptor 注册，bootstrap 契约版本为 `36`。普通调用绑定合法工号和 clientId，原生命令还要求原有 v4 握手及 HTTP 固定连接身份一致。业务写操作使用各自的校验与签名。普通 `command` 以第三参工作流 revision 做 CAS；`confirmDocumentVersion` 用预检快照而非该修订号，`reviewDocuments` 直接捕获接纳时最新已保存材料。命令按实际连接身份及 operationId 去重；同 ID 同内容显式重试返回原结果，复用 ID 但改内容则拒绝。重连只恢复订阅和重读。`readWorkflow`、`retrySession` 使用项目、IR 和 Agent 定位会话，命令目标只接受项目和 IR；这些目标均不接受 SR。`readRequirementDetails` 按项目组和 IR 业务号读取页面快照中的云龙字段和可用评论。`proposals.syncToRedZone` 通过服务端传输端口交接全量项目、IR 原始描述和当前需求文档，接收端仅写入随附的需求文档。列配置按连接工号在服务工作目录持久化，迁移写入只在记录缺失时生效。材料读取恢复绑定项目、Release、IR、路径和正文摘要。

在线人员由连接 owner 持有工号及 IP 引用计数。Release 统计从同一工作流按项目聚合。

工作流不把幂等记录当作操作历史下发。

配置读取经 bootstrap。模型和追加指令各自使用独立 revision；配置成功后服务端记录操作、实际操作者和时间，避免把配置正文记录进日志。隐藏 Skill 仍在已有原生会话和私有存储中工作。Skill 保存和读取共享唯一内存文件事实。

v4 请求及发出的帧使用现行严格 schema，会话操作继续由原生 runtime 对工作区、订阅及附件行校验。执行失败保留已接纳输入，在原生历史及投影返回相同的安全失败信息。
