# 设置搜索

提供设置项搜索入口和设置行定位。

- `SettingsSearch` 只持有当前对话框和查询草稿，不挂载未选中的设置页。
- 调用方可选择紧凑图标入口；搜索行为与默认入口一致，保留可访问名称与提示。
- 调用方提供当前应用可达的分区与显示名。外观分区使用固定索引，业务分区提供自己的设置行定位标识、文案和同义词。选择结果在弹窗焦点锁结束后交给调用方的导航门禁。
- SettingsPage 接收 SettingsSearchResult，沿用原导航，并持有唯一定位目标。设置行实际挂载时按稳定 id 滚动、聚焦和高亮；每次命中的高亮在约 2 秒后自动消失，不改变焦点或滚动位置。旧轮次到期不影响后续命中。
- 定位不操作控件，不保存配置，不更改 Host 或 workspace。查询与关闭对话框没有持久化副作用。
- `settingsSearchIndex` 登记浏览器外观设置行的翻译 id 与说明；同一 id 用于 `SettingsRow` 定位。业务条目的 id 由调用方保证稳定、唯一且指向实际可达区域。
- 通过 index.ts 公开组件、定位上下文和 hook；contract.ts 公开导航结果与定位 id 类型。内部匹配与索引不作为其他模块的业务状态源。
