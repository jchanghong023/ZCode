# 扩展协议类型

本模块仅保留扩展清单、插槽、能力、会话引用、日志、授权及视图消息的 schema、类型与纯函数。当前产品不装配扩展进程、网关或插件 UI，协议定义不构成公开服务。

- 清单先判断 engines 兼容，再严格解析 extension；未知字段返回带路径诊断。
- `EXTENSION_SLOTS` 与 `EXTENSION_CAPABILITIES` 分别是插槽与能力的唯一定义，类型从表推导，不维护第二套声明。
- target 只能指定一种目标；条目引用、字段、类型与限额校验失败只使该条目不可用。file.viewer 扩展名归一为小写去重列表。
- 静态表只表达解析事实；贡献快照换代整份替换，增量仅在同 gen 且 rev 增大时接纳，无底稿增量丢弃。
- grant 与协议兼容性由纯函数裁决；保留 sessions.read/write 等档位不授予当前调用方执行权限。
- 资源与消息只接受声明字段，跨进程形状不含函数或 AbortSignal。取消只通过显式协议表达。

会话控制输入与结果复用 `packages/session-control/src/CONTRACT.md` 对应 schema。所有状态、授权和副作用需要实际宿主实现，不能仅凭这些类型宣称已有运行能力。
